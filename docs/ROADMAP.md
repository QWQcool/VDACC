## 待办（1.x）

| 优先级 | 项 | 说明 |
|---|---|---|
| 中 | B站 番剧 | 番剧走独立接口与会员权限，和普通视频分开处理 |
| 中 | 封面 sidecar | 视频旁边落 `.jpg`，opt-in；字幕已实现 |
| 低 | 弹幕 | B站 XML 先落盘，转 ASS 需要额外转换器 |
| 中 | 失效探测 | 连续 N 次 `sign_rejected` 自动降级并提示升级 |
| 低 | L2 通用嗅探 | 仅直链/m3u8，blob/MSE 明确不支持 |
| 低 | 音乐专辑批量 | 显式 `--album`、上限 20、默认不勾选 |
| 低 | 移动端壳 | Android/Harmony，遥控模式，端上只跑纯 HTTP 引擎 |

## 暂缓（技术未成熟，不排期）

2026-10-21 决策：下载后的内容理解与生成侧整体暂缓。不是砍掉，是等前提成立。设计探讨保留在 `Plan.md §4`，但**不要按它开始排期**。

| 项 | 暂缓原因 | 重启条件 |
|---|---|---|
| 视频分析（抽帧 + 语音转写 + 画面理解） | 依赖下面两项才有意义 | 三视图或提示词任一具备可用性 |
| 人物三视图生成 | 跨视角一致性只到「参考级」，出不来能直接进 pipeline 的资产 | 角色一致性可控（LoRA / ControlNet 或模型原生支持） |
| 视频生成提示词反推 | 各模型提示词语义不统一，一套提示词复刻效果不可控 | 视频模型提示词规范收敛，且需要「按镜头切分」的模板层 |

## 明确不做

- DRM、付费内容、私密视频、直播
- 站点广度竞赛（交给 yt-dlp）
- 播放列表/歌单自动展开
- 端上跑 B站（依赖 yt-dlp/Python，不可移植）

## 维护节奏

- 每次改动：`python -m unittest discover -s tests -t .` 必须全绿
- 每周：对三个引擎各跑一次 `probe` 冒烟；平台改版时先看 `sign_rejected` 是否上升
- 发版：`tools/build_skill.py --zip` → 打 tag → Release 附 zip
