CURRENT STRUCTURE

薄入口，共用引擎，独立状态。

业务仍集中在 ts/src/engines；请求与任务的临时状态已经移入 operation 作用域。

入口

Web · CLI · Skill

Vue 提交任务与订阅 SSE；CLI 直接调用引擎；Skill 仅包含抖音 / B站 / 网易云 probe/get。

协调

本地服务与队列

token + 精确同源 → 先落盘再入队 → 单 worker 下载 → 终态存档 / SSE 快照。

引擎

专用 → L2 → generic

抖音、B站、网易云、QQ、酷我、酷狗；再由直链 / m3u8 与可选 yt-dlp 兜底。

共用基础层

types / errors / security / storage / operation / sidecar

HTTP 请求 A → scope A下载任务 B → scope B缓存 / 字幕 / 进度 / 取消独立

隔离并不等于并发已经开放。同步 ffmpeg、同名输出和限速预算仍是下一阶段必须处理的前提。
